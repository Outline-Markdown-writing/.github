# Outline — Hierarchical Notes with Markdown Support from Microsoft (Paid)

## About Outline

Outline provides a hierarchical notes application with Markdown support from Microsoft (paid version) for writers, project managers, students, and knowledge workers. Outline combines fold/unfold outlines, tagging, and cross-note linking. Outline supports task lists, note linking, and Markdown formatting. Outline syncs across iPhone, iPad, Mac, and Windows devices via cloud. Outline enables users to organize thoughts hierarchically, collapse sections for focus, and write in plain text Markdown. Outline is trusted by novelists, business strategists, academic researchers, and content creators worldwide.

## Deep Dive — Hierarchical Note Features
Fold/unfold outline nodes for progressive disclosure of sections
Markdown rendering for headings, bold, italic, lists, code blocks
Cross-note linking with backlinks for knowledge graph connections
Tagging system with tag cloud and filtered view by multiple tags
Task lists with checkboxes and priority/status filtering

## Quick Reference for Outline

| Operation | Outline Action |
|-----------|----------------|
| New note | Cmd+N |
| New child | Tab |
| New sibling | Return |
| Fold node | Left arrow |
| Unfold node | Right arrow |
| Toggle task box | Cmd+T |
| Insert link | Cmd+K |
| Markdown preview | Cmd+P |
| Search notes | Cmd+F |
| Open note links | Cmd+Click |
